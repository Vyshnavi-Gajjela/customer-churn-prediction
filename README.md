
# AI-Powered Customer Churn Prediction and Retention Analytics System
## Overview

This project predicts telecom customer churn using advanced Machine Learning and Deep Learning models.

The system performs:
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- SMOTE Balancing
- Model Training
- Explainable AI
- Risk Segmentation
- Retention Recommendation
- Streamlit Deployment

## Models Used

- Logistic Regression
- Random Forest
- XGBoost
- CatBoost
- Artificial Neural Network

## Features

- Advanced EDA
- Feature Engineering
- SMOTE Oversampling
- ROC-AUC Evaluation
- SHAP Explainability
- Feature Importance Analysis
- ANN Learning Curves
- Customer Risk Segmentation
- Retention Recommendation Engine
- Interactive Streamlit App

## Dataset

IBM Telco Customer Churn Dataset

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow
- XGBoost
- CatBoost
- SHAP
- Streamlit
